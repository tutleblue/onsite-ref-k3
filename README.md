# 두줄김밥 주문 · 주방 · 마감

| 화면 | 주소 |
|---|---|
| 주문 — 세 앱 주문 접수, 주문표 미리보기 · 인쇄 | `#/` |
| 주방 — 큰 글씨 주문 표시 | `#/kitchen` |
| 품절 — 메뉴 품절 켜고 끄기 | `#/soldout` |
| 정산 — 앱별 금액 · 장부 한 줄 복사 | `#/settle` |
| 발주 — 남은 재료 입력 · 거래처 문구 복사 | `#/supply` |

- 기록은 브라우저(localStorage)에 저장됩니다. 같은 컴퓨터에서 `#/kitchen` 창을 하나 더 띄우면 두 창이 같이 움직입니다
- 주문은 앱 안 시뮬레이터가 만듭니다(처음 연 때를 11:40으로, 10배속, 시드 고정). `다음 주문 바로 받기`로 기다리지 않고 받을 수 있습니다
- 수수료 요율 · 재료 환산값은 정산 · 발주 화면에서 바꿀 수 있습니다
- 처음부터: 정산 화면 맨 아래 `데모 처음부터`

## 실행

```
npm install
npm run dev
```

## 빌드 · 배포

```
npm run build     # dist/
npm run deploy    # Cloudflare Workers (정적 자산)
```
